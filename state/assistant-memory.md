# Assistant memory

Durable notes from conversations with Firas: preferences, standing
instructions, decisions, and the reasoning behind settings. Appended by the
assistant when Firas says something worth keeping; dated, one line each.
Injected into every assistant exchange. Firas can prune this file any time,
directly or by telling the assistant to forget something.

- 2026-08-02: System went live today: heartbeat on Managed Agents every 2 hours, assistant on Kimi K3 with instant Slack replies and direct write access on instruction.
